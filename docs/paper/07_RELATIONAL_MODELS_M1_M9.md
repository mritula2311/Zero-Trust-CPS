The input is a network of **local normality scores**, not raw acceleration or switch features. These models output one normality probability per target node; they are not the final two-trust policy.

## Masking and training contract

Invalid rows are excluded from losses and metric denominators. GCN removes their incident edges before graph degree normalization. Set models exclude them from aggregation or attention. Fixed-width models canonicalize invalid score blocks and retain explicit validity information. The final audit found NaN/Infinity could survive multiply-by-zero or masked dense operations: `_with_validity`, pooled training and runtime inactive-GCN inputs now replace invalid content before arithmetic. Finite historical benchmark observations remain separately checked through regression/parity evidence; historical artifacts are never silently regenerated by this documentation build.

These benchmark guarantees do not cover runtime-M6 class-weight calculation: its trainer counts inactive labels before applying a valid-only loss mask. The serving adapter canonicalizes inactive features, but a trainer correction requires a separate evaluated retrain.

A present validity bit by itself does not establish this property. Tests invoke actual scoring and pooled training, not a duplicate masking implementation: [nonfinite boundaries](../../tests/test_nonfinite_relational_boundaries.py), [set masking](../../tests/test_setmodel_pending_node_masking.py), [baseline masking](../../tests/test_gnn_baseline_pending_node_masking.py).

## Selection decision matrix

| Criterion | Evidence and recommendation |
|---|---|
| Macro-F1 / FPR / precision | M6 has the best canonical single-seed balance; see 13 B |
| Isolated/coordinated recall | M6 retains high recall in both; GCN isolated recall is zero at its selected threshold |
| ROC-AUC / PR-AUC | M6 ROC-AUC reported; main-table PR-AUC absent, so no ranking from missing fields |
| Topology | M3/M6 do not consume adjacency; strongest topology invariance by construction; M5 is sensitive |
| Permutation | Set outputs are equivariant under node relabelling; historical graph probe is not a valid equivariance test |
| Mixed cardinality | M8 is the explicit mixed-cardinality candidate; tested constructed subset robustness trades FPR |
| Mixed provenance | M9 is the explicit provenance candidate; LOW→HIGH stress reveals false alarms |
| Cost | M1 is fastest in the saved single-sample benchmark; M3 has a useful simplicity/cost tradeoff; M6 remains small |
| Calibration | Compare raw/isotonic Brier and alarm-cap rows separately; do not substitute max-F1 performance |
| Fusion complementarity | [UNKNOWN] No matched local-only versus M6-augmented fusion result |
| Deployment compatibility | Runtime M6 serving/checkpoint/fusion integration exists and passes offline scenarios; its three-channel checkpoint is distinct from benchmark M6. Correctly pinned comparative and physical validation remain open; see [10](10_FUSION_AND_PROCESS_TRUST.md). |

Best standalone candidate: M6. Simple topology-independent baseline: M3; fixed-width baselines: M1/M2. Mixed-cardinality and mixed-provenance variants: M8 and M9 respectively, without a claim that either dominates M6. M7 is retained as a negative complexity ablation; M4 is retained as an implemented runtime lineage and mechanism comparator. No universally best model or statistically significant M1–M9 ranking is established by one seed.

The separate M9 seed-study artifacts lack immutable input/version fingerprints. Their historical “n=10 real” and “15-column pool” labels must not be silently reinterpreted as current 20/25-node provenance. They are separated in [13](13_RESULTS_MASTER_TABLES.md) and [24](24_REPRODUCIBILITY_GUIDE.md). The historical virtual-only advantage remains inconclusive after masking/cardinality changes.
